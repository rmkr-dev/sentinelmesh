# Roadmap

Not in this version:

- AWS and GCP exporters. The domain model is ready for them; the collector config is not written.
- A learned anomaly model behind the existing `Detector` interface.
- eBPF collectors.
- Automatic dependency discovery beyond the catalog and trace samples.
- Predictive incidents.
- A recorded evaluation set for model answers.
- Multi-cluster and multi-region views.
- FinOps joins between spend and incidents.
- Generated remediation plans that execute themselves. Approval stays mandatory.

These are intentionally not stubbed in the code.
