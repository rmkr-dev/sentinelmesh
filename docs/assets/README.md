# Screenshots

Do not commit a picture of a dashboard that was not produced by this stack.

To capture the local UI after `make up` and `make demo`:

1. Open http://localhost:3000/d/exec-overview and export a browser screenshot to `docs/assets/grafana-executive.png`.
2. Open http://localhost:3000/d/slo for `docs/assets/grafana-slo.png`.
3. Open an incident in http://localhost:8080/ui/ for `docs/assets/incident-timeline.png`.
4. Run `obsctl incident analyze` and save the JSON beside the screenshot as `docs/assets/rca-result.json` if you want a text artifact. The JSON is generated by the API; do not hand-write it.

The diagrams in `docs/architecture` are Mermaid sources and match the packages and compose file. They are not screenshots.
