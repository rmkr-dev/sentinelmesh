# Security policy

Report vulnerabilities privately to the repository maintainers. Do not open a public issue that includes a working exploit, a connection string, or customer data.

The platform's controls are described in [docs/security/threat-model.md](docs/security/threat-model.md) and [docs/security/security-controls.md](docs/security/security-controls.md).

Supported version: 0.1.x on the main branch.
